# Quiz App

A simple and interactive Quiz App built using **HTML, CSS, and JavaScript**. It tests users' knowledge of web development through multiple-choice questions.

## Features

- Multiple-choice quiz questions
- Instant feedback for correct and incorrect answers
- Score tracking
- Question progress indicator
- Next button to navigate between questions
- Reset option to restart the quiz
- Simple and user-friendly interface

## Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Quiz logic, answer validation, and score calculation

## Topics Covered

- HTML and CSS fundamentals
- JavaScript variables and functions
- Arrays and objects
- DOM manipulation
- Event handling
- Conditional statements

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start answering the quiz questions!

## How to Play

1. Read the displayed question.
2. Select one of the available answers.
3. Get instant feedback on your selection.
4. Click **Next** to continue.
5. View your final score after completing the quiz.
6. Click **Reset** to play again.
